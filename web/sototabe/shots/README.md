# アプリ画面の差し込み

次のファイル名で置くと、紹介ページが自動で表示します（jpg / png / webp 可）。

| ファイル | 元画像 | 用途 |
|----------|--------|------|
| `hero-main.jpg` | 01.jpg | ヒーロー正面の端末 |
| `feature-01.jpg` | 04.jpg | できること・カテゴリ |
| `feature-02.jpg` | 02.jpg | できること・訪店評価 |
| `feature-03.jpg` | 03.jpg | できること・共有 |
| `feature-04.jpg` | 05.jpg | できること・最近訪れたお店 |

推奨: 縦長（約 9:19.5）の実機スクショ。角丸は CSS 側でクリップされます。
