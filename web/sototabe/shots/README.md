# アプリ画面の差し込み

次のファイル名で PNG / WebP を置くと、紹介ページが自動で表示します。

| ファイル | 用途 |
|----------|------|
| `hero-main.png` | ヒーロー正面の端末 |
| `hero-sub.png` | ヒーロー後ろの端末 |
| `feature-01.png` | できること・カテゴリ |
| `feature-02.png` | できること・訪店評価 |
| `feature-03.png` | できること・共有 |
| `flow.png` | 使い方セクション |

推奨: 縦長（約 9:19.5）の実機スクショ。角丸は CSS 側でクリップされます。
