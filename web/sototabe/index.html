そとたべ

外食お気に入りを、ジャンル・地区で自由に整理・記録するアプリ

地図アプリの代替ではなく、「行った店」「また行きたい店」を自分用のリストとして残すためのツールです。アカウント登録は不要で、データは端末内に保存されます。

App Store 公開準備中

こんな方におすすめ

  • 行ったお店の名前や感想を忘れたくない方
  • ラーメン・カフェなど、ジャンル別にお店を分けたい方
  • 渋谷・横浜など、地区・エリア別にリストを作りたい方
  • 再訪したい店の評価・予算・支払い方法をメモしておきたい方
  • 公開せず、自分だけの記録を残したい方

主な機能

  • カテゴリ（ジャンル / 地区 / シーン）で自由に整理
  • 訪店メモ・星評価・お会計・項目別評価
  • 写真・レシートで「何を食べたか」を履歴に残す
  • 電話・地図・公式サイトへワンタップ
  • お店情報の共有ファイル（.sototabe）送受信

無料とプレミアム

  • 無料版: 主要機能すべて + バナー広告 + カテゴリ最大3個 + お店情報の受信
  • プレミアム（¥600・買い切り）: 広告なし + カテゴリ最大16個 + お店情報の送信
